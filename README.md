# Phalloceros COI — DIYABC and ABC-RF analyses

COI-based demographic analyses of Phalloceros from three
geomorphological compartments of Macaé river: Mountain Escarpment,
Rounded Foothills, and Lowland Plain.

This repository will contain the COI input files (.mss),
DIYABC project configurations, reference tables, analysis
scripts, and results.

Analyses include demographic scenario comparison,
sensitivity to simulation-table size, parameter estimation
conditional on Scenario 2, and prior predictive checks.

Repository under construction.
